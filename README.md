# Rensar

Website for Rensar Design Consulting and its games label, Rensar Play.

A static site with no build step. Open `index.html` in a browser, or serve the folder with any static host (for example GitHub Pages).

- `index.html`: Rensar Design Consulting, with Rensar Play on the same page (`#play`)
- `privacy.html`: Unspoken privacy policy, linked from the footer
- `play.html`: redirects to `index.html#play`
- `styles.css`, `site.js`: shared styles and scroll animations
- `img/`: favicon and Unspoken app screens
